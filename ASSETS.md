# Asset sources and notices

Retrieved on 2026-09-14 and 2026-09-15. Original third-party notices are preserved alongside the files. This project is not endorsed by the named manufacturers.

## Franka Panda

- Source: [Franka Robotics / franka_ros](https://github.com/frankarobotics/franka_ros/tree/noetic-devel/franka_description).
- Files: `public/models/franka/link0.dae` through `link7.dae`, `franka_arm.xacro`, `joint_limits.yaml`.
- License: Apache-2.0, retained in `public/models/franka/LICENSE`.
- The downloaded mesh files are unchanged. `robot.urdf` is a derived visual-only description generated by `scripts/prepare-franka.mjs` from the official joint origins and limits; collision, inertia, ROS and controller macros are omitted. The original link7 visual rotation is preserved.
- Browser display uses a uniform 2.4× scene scale and a Three.js CCD IK adapter. This is a visual demonstration, not a validated physical robot controller.

## Legacy LEAP source

- Source: [LEAP Hand / LEAP_Hand_Sim](https://github.com/leap-hand/LEAP_Hand_Sim/tree/master/assets/leap_hand).
- Files: `public/models/leap/robot.urdf` and eight original STL meshes.
- Upstream repository license: MIT, copyright 2023 Ananye Agarwal, retained in `public/models/leap/LICENSE.txt`. Upstream README is retained as `SOURCE_README.md`.
- These unchanged original files are retained for provenance. The active preset now uses the paired left/right GLB descriptions in the expanded catalog below; the legacy single-side model is no longer rendered.
- Separate fabrication CAD distributions may have different terms; this project's source is specifically the simulation repository listed above.

## Piano

- `components/GrandPiano.tsx` is an original procedural Steinway-style concert grand with 88 independently animated keys. It is not an official Steinway model or a dimensionally accurate D274 reproduction. It uses no copied Steinway logo.
- Candidate real model: [Steinway D274 by seavenois, BlendSwap](https://blendswap.com/blend/7279), listed as CC0, 16.2 MB. Download required account login, so it was **not downloaded or included**.

## Scores and sound

- “Frère Jacques” and “Twinkle, Twinkle, Little Star” use traditional public-domain melodies, entered as note events with a simple accompaniment for this project. No third-party score file or commercial arrangement is bundled.
- Sound is synthesized per note with Web Audio oscillators and decaying harmonics. No song recording or piano sample library is bundled.

## Libraries

- Three.js / React Three Fiber / Drei: rendering, geometry, camera, shadows and CCDIKSolver.
- urdf-loader: URDF parsing and articulated model loading; Three.js STLLoader, ColladaLoader and GLTFLoader handle referenced mesh files.
- Lucide: interface icons.

Dependency versions are locked in `package-lock.json`; their licenses remain in their npm packages.

## Expanded hardware catalog

`public/models/catalog-sources.json` records the exact upstream commit, source URDF and local URL for every added model. Upstream original descriptions are retained beside adapted descriptions as `.urdf.source`.

- Universal Robots UR5e, KUKA LBR iiwa 7, Allegro, LEAP and Shadow: https://github.com/dexsuite/dex-urdf. This repository supplies GLB conversions and left/right hand variants. Per-model license files and the repository notice are retained in `public/models/vendor/dex/`. See its README for original manufacturer repositories. The aggregate repository license does not replace individual asset licenses.
- Flexiv Rizon 4 and mirrored Rizon 4R: https://github.com/flexivrobotics/flexiv_rdk/tree/v1.7/resources. Official OBJ/MTL visual assets and kinematic descriptions, pinned to the v1.7 source commit. Apache-2.0 notice retained.
- Sharpa Wave: https://github.com/sharpa-robotics/sharpa-urdf-usd-xml. Official independent left/right descriptions, visual STL meshes and URDF material colors. LICENSE.txt and NOTICE.txt retained.
- Wuji Hand: https://github.com/wuji-technology/wuji-description. Official stable `hand/body` left/right assets (not the beta second-generation model). MIT notice retained.
- Tianji Marvin: https://en.tianjizn.com/. The public download center provides product documents; no suitable public URDF/visual mesh download was located. Its catalog option remains disabled rather than substituting a different arm.

STL files contain geometry, not texture images. Their appearance comes from URDF material colors. GLB and OBJ/MTL materials are preserved rather than globally replaced with a silver material. Both copies of a symmetric arm may share a model; hands always use their distinct upstream side descriptions. Flexiv uses the published mirrored 4R for the right side.
