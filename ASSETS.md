# Asset sources and notices

Retrieved on 2026-09-14. Original third-party notices are preserved alongside the files. This project is not endorsed by the named manufacturers.

## Franka Panda

- Source: [Franka Robotics / franka_ros](https://github.com/frankarobotics/franka_ros/tree/noetic-devel/franka_description).
- Files: `public/models/franka/link0.dae` through `link7.dae`, `franka_arm.xacro`, `joint_limits.yaml`.
- License: Apache-2.0, retained in `public/models/franka/LICENSE`.
- The downloaded mesh files are unchanged. `robot.urdf` is a derived visual-only description generated by `scripts/prepare-franka.mjs` from the official joint origins and limits; collision, inertia, ROS and controller macros are omitted. The original link7 visual rotation is preserved.
- Browser display uses a uniform 2.4× scene scale and a Three.js CCD IK adapter. This is a visual demonstration, not a validated physical robot controller.

## LEAP Hand

- Source: [LEAP Hand / LEAP_Hand_Sim](https://github.com/leap-hand/LEAP_Hand_Sim/tree/master/assets/leap_hand).
- Files: `public/models/leap/robot.urdf` and eight original STL meshes.
- Upstream repository license: MIT, copyright 2023 Ananye Agarwal, retained in `public/models/leap/LICENSE.txt`. Upstream README is retained as `SOURCE_README.md`.
- Mesh and URDF files are unchanged. Browser materials are recolored silver, model scale is 2.5× and finger joint angles are animated for this demo. The supplied right-hand model is instantiated twice; this is not an independently sourced left-hand CAD model.
- Separate fabrication CAD distributions may have different terms; this project's source is specifically the simulation repository listed above.

## Piano

- `components/GrandPiano.tsx` is an original procedural Steinway-style concert grand with 88 independently animated keys. It is not an official Steinway model or a dimensionally accurate D274 reproduction. It uses no copied Steinway logo.
- Candidate real model: [Steinway D274 by seavenois, BlendSwap](https://blendswap.com/blend/7279), listed as CC0, 16.2 MB. Download required account login, so it was **not downloaded or included**.

## Scores and sound

- “Frère Jacques / 两只老虎” and “Twinkle, Twinkle, Little Star / 小星星” use traditional public-domain melodies, entered as note events with a simple accompaniment for this project. No third-party score file or commercial arrangement is bundled.
- Sound is synthesized per note with Web Audio oscillators and decaying harmonics. No song recording or piano sample library is bundled.

## Other robot presets

UR5, Flexiv, 天机, Sharpa and Wuji currently select original stylized procedural geometry. They are not downloaded manufacturer CAD or certified descriptions. The lightweight mode also uses procedural geometry for Franka and LEAP.

## Libraries

- Three.js / React Three Fiber / Drei: rendering, geometry, camera, shadows and CCDIKSolver.
- urdf-loader: URDF parsing and articulated model loading; Three.js STLLoader, ColladaLoader and GLTFLoader handle referenced mesh files.
- Lucide: interface icons.

Dependency versions are locked in `package-lock.json`; their licenses remain in their npm packages.
